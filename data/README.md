# `data/`

> Data directory — SQL migration scripts for the FMCG supply chain PostgreSQL database.

## Overview

This folder contains the migration scripts used to create and seed the PostgreSQL database. The FMCG business data and the pgvector few-shot store both live in the same PostgreSQL instance.

This is exclusively for the **FMCG business data** that the SQL Agent queries. Chat history and session data live in MongoDB (a separate Docker service).

## Structure

```
data/
└── migrations/
    ├── 001_initial_schema.sql   # Table definitions (PostgreSQL DDL)
    └── 002_seed_data.sql        # Mock data (generated by portal/backend/db/seed.py)
```

## Database

The PostgreSQL database is populated by running the seeder:

```bash
cd portal/backend
python -m portal.backend.db.seed
```

This creates all tables from `001_initial_schema.sql` and populates them with realistic FMCG supply chain data for the Indian F&B market (Jan–Dec 2025).

## Docker Volume

In `docker-compose.yml`, PostgreSQL data is persisted via a named volume managed by the PostgreSQL container:

```yaml
volumes:
  postgres-data:    # persists PostgreSQL data (FMCG + pgvector) across restarts
```

Data survives `docker-compose down`. Only `docker-compose down -v` deletes volumes.
