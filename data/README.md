# `data/`

> Data directory — SQLite database file and SQL migration scripts for the FMCG supply chain dataset.

## Overview

This folder contains the SQLite database file (`genbi.db`) and the migration scripts used to create and seed it. In Docker, this directory is mounted as a **named volume** so data persists across container restarts.

This is exclusively for the **FMCG business data** that the SQL Agent queries. Chat history and session data live in MongoDB (a separate Docker service).

## Structure

```
data/
├── genbi.db               # SQLite database (generated by seed.py, gitignored)
├── faiss_index/            # FAISS vector store files (generated, gitignored)
└── migrations/
    ├── 001_initial_schema.sql   # Table definitions
    └── 002_seed_data.sql        # Mock data (generated by backend/db/seed.py)
```

## Database

The SQLite database (`genbi.db`) is generated by running the seeder:

```bash
cd backend
python -m backend.db.seed
```

This creates all tables from `001_initial_schema.sql` and populates them with realistic FMCG supply chain data for the Indian F&B market (Jan–Dec 2025).

## Docker Volume

In `docker-compose.yml`, this directory maps to a named volume:

```yaml
volumes:
  sqlite-data:    # persists genbi.db across restarts
  faiss-data:     # persists FAISS index across restarts
```

Data survives `docker-compose down`. Only `docker-compose down -v` deletes volumes.
